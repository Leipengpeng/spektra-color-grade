# 固定工具流与PSD语义

用户：选择效果和可选偏好 → Agent：调用spektra_psd → 工具：验证输入、编译参数、渲染、写PSD／PSB、独立图层重合成验收 → Agent：展示压缩对照并交付本地文件。需要算法级修改时调用recipe，不直接修改已交付文件。

## 五阶段及全局调整

base关闭相机AE、manual EV和用户曝光调整，printExposure=1，同时关闭用户的光晕、DIR和颗粒。exposure应用用户AE、manual EV与printExposure；接着依次启用halation（含乳剂scatter）、DIR、grain。五张真实引擎阶段图记为Y0至Y4。

令P是在同一原片和同一设置下执行的统一后处理，包含明暗、冷暖、反差、饱和度、褪色以及整体力度strength。各Yi分别应用同一个P，不能只在最顶层补一个最终混合差分，否则strength降低时可能抵消下方颗粒层。分层链从raw Y0开始，随后依次为 `P(Y0)−Y0`、`P(Y1)−P(Y0)`、`P(Y2)−P(Y1)`、`P(Y3)−P(Y2)`、`P(Y4)−P(Y3)`。它们相加重建P(Y4)，每个相邻物理阶段均使用一致的后处理坐标。

颗粒是最后一个效果层，降低它趋向P(Y3)，即同样全局调整后的无颗粒条件阶段；整体力度为0时，所有P(Yi)都等于处理尺寸原片，因此曝光、光晕、DIR和颗粒差分均为0。这里不把PS滤镜当作原模型，其他关层、改底图和多层组合仍不保证原引擎反事实。

Python模式关闭未暴露的glare、扫描锐化和额外镜头效果以保证受控、可复现；native wire不能关闭的固定选项会披露。后端之间不承诺同参数像素一致。Python颗粒RNG适配使用同分布固定采样，具体映射记入metadata；native seed限制不隐瞒。

## 16位Linear Light差分层

相邻阶段结果之差为 `Δ=Yi−Yi−1`。差分层以默认不透明度 `a=opacity/255` 和编码增益 `g=1/a` 保存 `S=(gΔ+1)/2`，使用Linear Light重组。合成器先裁切混合结果再应用不透明度：`B′=(1−a)B+a·clip(B+2S−1,0,1)`。为了默认重建并保留可增强空间，工具按每层的最大差值及当前底图到黑白端点的余量求安全a，向上取到PSD不透明度字节，范围128–255。只把默认设为50%可能在暗部或高光提前裁切，不能作为通用保真做法。

所有数组在同一encoded sRGB、尺寸和方向，分层文件嵌入sRGB ICC。PSD和PSB均为原生16bpc，使用Lr16层记录，每个通道16位，保留中文层名和独立merged预览。PSB使用v2头和对应64位长度字段，不是给PSD改后缀。没有最终图盖住所有效果层的伪分层。

图层固定8层，从底到顶为：可见“原片底图（保留）”、基础调色、全局冷暖与力度（基础条件差分）、曝光与印相、光晕、DIR、颗粒、透明“后续修饰”。原片底图是本次色管／定尺寸后的源图；原始磁盘文件始终保留不变。基础调色保留raw Y0，默认Normal不透明度100%，降低它会露出原片，上方差分仍叠加；透明修饰层默认空白，留给用户继续修图。

“全局冷暖与力度（基础条件差分）”只保存 `P(Y0)−Y0`，用于把基础阶段带到统一后处理坐标。单独改变这个层的不透明度，不等于重新设置整张照片的冷暖或strength。真正的全局参数修改需沿用recipe重新渲染各阶段。

差分层默认约50.2%–100%，具体值见layers.json中的default_opacity（0–255字节）、default_opacity_percent、encoded_gain和boost_at_100_percent。低于默认可减弱，有余量时调到100%可增强；例如默认128／255时编码增益约1.992，但最后的增强仍会受当前底图和裁切影响。强烈或饱和变化可能必须默认100%，没有剩余不透明度空间。复制差分层可以艺术叠加，不能承诺无裁切、无损增强或等于物理模型重新渲染。

高位深量化、Linear Light及混合gamma会影响数值。本工具默认按编码sRGB合成，验证记录该约定；用户改变文档颜色空间或Blend RGB Colors Using Gamma选项，应重新对照graded.tif。差分层本身是数据，单独套非线性色彩转换会改变含义。

默认可见性、顺序和不透明度用于在量化误差范围内重建此次成片。调不透明度、复制层或蒙版是创作编辑，不等于重新计算原算法的强度参数。任意删层、换底图、换材料后要求模型正确联动，应由Agent重渲染。保存完整参数与固定随机方式是重算的依据。

用户在PS中追加的手工修饰请另存；通过recipe重新渲染会生成新PSD，不自动读取或合并旧PSD里的手工图层。原PSD及原始照片都保留，不覆盖。

## 自动验证与开放编辑器测试

每次交付前独立读取实际分层文件，核查头、16位通道、ICC、图层可见性、不透明度和混合模式，绕过内嵌预览从图层重算，比较merged和16位参考。还需确认有实际贡献的效果层关闭或减弱时结果改变；具备增强余量的层可做增强调节验证。

小图走开源psd-tools强制图层合成。大像素数、大文件或任一边超过30000时，改用独立raw16 PSD／PSB解析器，将通道映射到磁盘并逐像素块执行Normal／Linear Light合成和比较，避免为验证再分配整图浮点数组。大图路径是独立实现，不能称为psd-tools全尺寸重合成；它只验收本工具生成的raw16层结构，不是任意第三方PSD效果的通用验证器。validation.json记录实际验证器、选择方式、误差及门限。若不通过，整个输出目录不提交。

开放编辑器验收使用GIMP加载实际PSD或PSB并导出，另用保留旧merged但隐藏效果层的样本，排除只读取缓存的假通过。每种格式和具体输出分别记录，不能从小图读写推断大图已完成编辑器验收。GIMP／psd-tools与Adobe是不同实现；没有实际完成的测试不得标通过。Krita本机启动失败，未标通过。

2026-11-13最终布局已在GIMP3.2.8实测512×341、16位8层PSB：默认导出对TIFF参考最大差4/65535；颗粒默认177/255，减到88/255及提高至255/255均正确响应。另一个只改1字节可见性、merged完全相同的文件仍产生不同合成。逐通道0/88/177测试无单调违规。该结果证明此次小图的实际互操作性，不扩展为所有尺寸或Adobe认证。

## 原尺寸、大图与格式选择

默认max_edge=0，保留EXIF转正后的原尺寸。max_edge为1–300000时仅缩小超过限制的长边。显式width／height各为1–300000：填一边自动按比例计算另一边；填双边默认要求保持比例，明确resize_mode=stretch才允许拉伸。非零max_edge与显式宽高互斥。放大是重采样，不增加原始细节。

document_format=auto在宽高任一边超过30000，或预计分层文件超过2GB时选择PSB，实际输出以返回路径为准。显式psb可用于小图；显式psd不能绕过PSD的尺寸和文件大小限制。PSB单边最多300000，格式上限不等于本机已经测试过或能够完成所有尺寸。

输出不设统一总像素上限。输入、中间帧与写入按磁盘映射和分块方式降低内存占用，实际仍受工作磁盘空间、内存／显存、后端实现及编码器约束；引擎内部的计算需求不能由PSB容器消除。资源不足会返回错误，不静默降低尺寸。压缩预览独立生成，评审流量不决定主文件分辨率。

## 输出文件

graded.psd或graded.psb：可继续编辑分层文件；graded.tif：16位sRGB参考；preview.jpg与comparison.jpg：低流量审片；recipe.json：重新调用入口；layers.json：层、默认不透明度、增强余量和参数清单；validation.json：文件／合成质量；PS使用说明.md：操作与语义；delivery.zip：默认压缩交付包。archive=false／--no-archive时不生成ZIP，其他交付不受影响。

原子生成到新目录，失败不产生残缺交付，不覆盖旧目录。分层文件本身可能较大，Agent只展示压缩图、提供本地文件链接，不自动上传PSD／PSB或全分辨率图片。
